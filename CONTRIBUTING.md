# Contributing to HyperDimension Lab

Thanks for taking an interest in the project. A useful contribution can be an algorithm correction, an accessible interaction improvement, a documented example or a clearer explanation of the mathematics.

## Before sending a change

1. Check whether there is already an issue describing the problem.
2. Keep changes focused and explain the reasoning in your pull request.
3. For geometry changes, include a test demonstrating the expected counts or invariants.
4. Run `npm run check` and `npm test`.
5. Avoid external dependencies unless there is a measurable benefit and maintenance plan.

## Standards

The interface aims to be useful without a graphics card, network connection or account. Please keep keyboard interaction, reduced-motion support, accurate mathematical language and mobile layout in mind.
