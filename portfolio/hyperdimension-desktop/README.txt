4D DESKTOP EXPLORER - WINDOWS

Start the app
1. If you downloaded a ZIP, right-click it and choose Extract All.
2. Open the extracted 4D-Desktop folder.
3. Double-click Start-4D.cmd.

The app opens in its own Microsoft Edge window. It uses the Edge installation
already on your laptop. It needs no internet, server, account, administrator
permission, package installation, or subscription.

Keep every file in this folder together. You can move the complete folder
anywhere. To create a shortcut, right-click Start-4D.cmd, choose Show more
options if needed, then Send to > Desktop (create shortcut).

If your computer blocks scripts, double-click index.html instead. This opens
the same offline 4D experience in a normal browser tab. If Edge is missing,
the launcher automatically uses your default browser.

Explore
- Choose a 4D object from the example library.
- Drag the view to orbit the 3D projection; use the wheel to zoom.
- Use the rotation controls to rotate in true 4D coordinate planes.
- Compare perspective and orthographic projection.
- Switch to the slice view and change the cutting plane position.
- Use the in-app guide for explanations and guided experiments.

What this is
This is a portable local web app with a dedicated desktop window, not a
compiled Windows executable or a Microsoft Store installation. The desktop
edition is restricted to four dimensions. Higher-dimensional objects cannot
be shown directly on a flat display; the app shows mathematical projections
and cross-sections, with explanations in the guide.

Remove
Close the app and delete the 4D-Desktop folder and any shortcut you created.
There is no installed service and no system setting to restore.
