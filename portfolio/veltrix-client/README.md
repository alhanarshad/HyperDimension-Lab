# Veltrix Client

Veltrix is an independent Windows launcher preview for Minecraft Java Edition with an associated Fabric client. It supports isolated game instances, file verification and repair, mod imports, a local cosmetics preview, and configurable graphics and HUD settings.

This public subset includes version validation, path and download safety checks, selected tests, and the original in-game component license. The complete local source archive contains the launcher, Fabric client, artwork, and notices. The full local Rust workspace passed 21 tests. The public subset is intended for code review and needs the complete archive to build.

The launcher preview requires an authorized Minecraft Services application ID for account sign-in. The signed-in launch path was outside the verified preview.
