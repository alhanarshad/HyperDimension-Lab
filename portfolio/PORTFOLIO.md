# Project portfolio

## Tools and demos

| Project | What it does | How to check it |
| --- | --- | --- |
| [Rational Row](rational-row/) | Exact linear-system solver with replayable row operations and a nullspace basis | Run the Python example and unit tests |
| [Split Telemetry](split-telemetry/) | Compares two runs by distance and reports cumulative and per-sector differences | Run the CLI on the two example CSVs |
| [Asset Ledger](asset-ledger/) | Verifies release-file checksums and declared attribution files | Audit the included manifest |
| [Trail Grade](trail-grade/) | Browser-local elevation analysis with a chart and steep-section table | Serve the folder locally and load the example |
| [Switchback Scene](switchback-scene/) | Editable Blender mountain road with procedural terrain, vegetation, and road geometry | Open the `.blend` scene or regenerate it |
| [Birthday Quest](birthday-quest-template/) | Generic celebration page with a playable star quest and riddle | Open `index.html` |

[HyperDimension Lab](../) is the geometry project at this repository root.
