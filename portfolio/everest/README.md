# Everest starter datapack

Development datapack for a Minecraft Java 1.21.11 mountain adventure. It contains the commands for a furnished lodge, access improvements, farm structures, trail sections, a fortress, and a local lake.

Copy `everest_home` to a disposable world's `datapacks/` directory. Reload datapacks and use `/function everest:help` before running any build functions. Commands use absolute coordinates from the original development terrain. Running them in another world can replace existing blocks at those coordinates.

The historical test confirmed server startup and access to the starter lodge. The full terrain save and third-party Fabric mods are separate. The final landscape and visual gameplay have not been completed.
