# Birthday Quest

A reusable celebration page with a star collection, a riddle, a final note, and a restart button. Open `index.html` directly in a browser. The page uses local HTML, CSS, and JavaScript and has no media dependencies.

Run `node --test test_quest.cjs` to verify the quest sequence and restart behavior.

Edit the prompts and note in `index.html`, and update the accepted riddle answer in `quest.js` when you change the riddle. The riddle is part of the activity. Browsers can read the answer and the note from source, so keep private material outside the page.

This is a generic adaptation of a personal celebration project. The public source uses fictional sample copy and contains no original recipient names, media, dates, or messages.
